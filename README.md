# Backtrader Stock Trading Bot

## Overview

This project is a Python-based stock trading bot utilizing the Backtrader framework. Its primary purpose is to demonstrate a Simple Moving Average (SMA) crossover trading strategy, showcase Backtrader's capabilities for backtesting, and serve as an educational tool for individuals looking to understand basic algorithmic trading concepts, strategy implementation, and performance analysis.

## Features

*   Implements a Simple Moving Average (SMA) Crossover strategy with two SMAs (fast and slow).
*   Dynamic loading of CSV data files (searches for `sample_imf_data.csv` or other `.csv` files if not found).
*   Includes a basic percentage-based stop-loss mechanism to limit potential losses on trades.
*   Utilizes Backtrader's powerful engine for event-driven backtesting of the strategy.
*   Integrates standard Backtrader analyzers:
    *   `SharpeRatio`: For risk-adjusted return measurement.
    *   `TradeAnalyzer`: For detailed statistics on trades (wins, losses, PnL, etc.).
    *   `SQN` (System Quality Number): For evaluating system performance.
    *   `DrawDown`: To measure the maximum peak-to-trough decline during a specific period.
    *   `AnnualReturn`: To provide annualized returns.
*   Saves the output plot to a file (`backtest_plot.png`).
*   More robust error handling during the backtest execution, especially for data sufficiency.
*   Provides extensive comments throughout the `backtrader_app.py` script to explain code sections, logic, and Backtrader concepts.
*   Includes conceptual notes within `backtrader_app.py` for extending the bot for live trading and comparisons with other algorithmic trading frameworks like QuantConnect LEAN and Freqtrade.

## File Structure

*   `backtrader_app.py`: The main Python script containing all the Backtrader logic. This includes data feed handling, strategy definition (SMA Crossover with stop-loss), Cerebro engine setup, analyzer integration, and detailed conceptual comments for further learning and framework comparisons.
*   `sample_imf_data.csv`: A sample CSV data file containing OHLCV (Open, High, Low, Close, Volume) data, used to demonstrate the bot's functionality out-of-the-box.
*   `README.md`: This file, providing an overview and instructions for the project.
*   `TUTORIAL.md`: A step-by-step guide for setting up, understanding, and using the bot, including customization tips.
*   `backtest_plot.png`: (Generated on successful run with trades) Plot image showing candlestick chart, volume, indicators, and trades.

## Prerequisites

*   Python 3.7+
*   pip (Python package installer)

## Installation

1.  Clone the repository (or download the files).
2.  Navigate to the project directory:
    ```bash
    cd path/to/your/project-directory
    ```
3.  (Recommended) Create and activate a virtual environment:
    *   On Linux/macOS:
        ```bash
        python3 -m venv venv
        source venv/bin/activate
        ```
    *   On Windows:
        ```bash
        python -m venv venv
        venv\Scripts\activate
        ```
4.  Install required libraries:
    ```bash
    pip install backtrader matplotlib
    ```

## Running the Bot

Execute the main script from the project directory:

```bash
python backtrader_app.py
```

## Output

*   **Console Output:** The script will print detailed logs to the console, including:
    *   Messages related to dynamic CSV file loading (e.g., "Using preferred data file...", "Multiple CSV files found...", "No CSV data files found...").
    *   Buy/sell signals generated by the strategy.
    *   Order statuses (submitted, accepted, executed, canceled, etc.).
    *   Results of executed trades (price, cost, commission, profit/loss).
    *   Starting and final portfolio values.
    *   Key metrics from the integrated analyzers (Sharpe Ratio, SQN score, DrawDown, AnnualReturn, and a summary from TradeAnalyzer showing total trades, winning/losing trades, net PnL, etc.).
*   **Plot:** A plot image (`backtest_plot.png`) is saved in the project directory upon successful completion of a backtest that includes trades. This image shows the candlestick chart, volume, SMA indicators, and buy/sell markers. If `enable_plotting` is set to `False` in the script, or if no trades occur, the plot generation might be skipped or be empty.

## Future Enhancements & Further Learning

This bot serves as a foundational example. You can extend and enhance it in numerous ways:

*   **Explore Conceptual Comments:** Dive into the conceptual comments within `backtrader_app.py`. They offer insights into:
    *   **Parameter Optimization:** Using `cerebro.optstrategy()` for testing various parameter sets (e.g., SMA periods, stop-loss percentages).
    *   **Alternative Indicators:** Incorporating other technical indicators like RSI, MACD, Bollinger Bands.
    *   **Advanced Sizers:** Implementing different position sizing strategies beyond `FixedSize` (e.g., `PercentSizer`).
    *   **Additional Analyzers & Observers:** Utilizing tools like `DrawDown`, `AnnualReturn`, or `PyFolio` for deeper performance insights, and Observers like `Broker` or `Trades` for visual feedback.
    *   **Live Trading Adaptations:** Understanding the high-level considerations for transitioning to live trading, including broker integration, real-time data handling, and robust error management.
    *   **Cerebro Writers:** Learning how to use `cerebro.addwriter()` to save backtest results to files.
    *   **Alternative Backtrader Frameworks:** The conceptual comparisons to QuantConnect LEAN and Freqtrade provide context on different algorithmic trading system architectures.

*   **Consult `TUTORIAL.md`:** This document provides a detailed, step-by-step guide on using, understanding the internal workings of, and customizing the bot's components. It's an excellent resource for a deeper dive into the script's functionality.

*   **Official Backtrader Documentation:** For comprehensive information on its API, all features, and advanced usage, the official documentation is invaluable: [https://www.backtrader.com/docu/](https://www.backtrader.com/docu/)

*   **Expand Financial & Programming Knowledge:**
    *   Continuously learn about financial markets, diverse trading strategies, quantitative analysis techniques, and robust risk management practices.
    *   Strengthen your Python programming skills, as this will enable more complex strategy development and customization.

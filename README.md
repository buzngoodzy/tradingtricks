# Backtrader Stock Trading Bot

## Overview

This project is a Python-based stock trading bot utilizing the Backtrader framework. Its primary purpose is to demonstrate a Simple Moving Average (SMA) crossover trading strategy, showcase Backtrader's capabilities for backtesting, and serve as an educational tool for individuals looking to understand basic algorithmic trading concepts, strategy implementation, and performance analysis.

## Features

*   Implements a Simple Moving Average (SMA) Crossover strategy with two SMAs (fast and slow).
*   Loads historical stock data from CSV files (a sample file `sample_imf_data.csv` is provided).
*   Includes a basic percentage-based stop-loss mechanism to limit potential losses on trades.
*   Utilizes Backtrader's powerful engine for event-driven backtesting of the strategy.
*   Integrates standard Backtrader analyzers:
    *   `SharpeRatio`: For risk-adjusted return measurement.
    *   `TradeAnalyzer`: For detailed statistics on trades (wins, losses, PnL, etc.).
    *   `SQN` (System Quality Number): For evaluating system performance.
*   Generates a plot of the trading activity, including candlestick price action, volume, SMA indicators, and buy/sell markers on the chart (plotting can be disabled for headless environments).
*   Provides extensive comments throughout the `backtrader_app.py` script to explain code sections, logic, and Backtrader concepts.
*   Includes conceptual notes within `backtrader_app.py` for extending the bot for live trading and comparisons with other algorithmic trading frameworks like QuantConnect LEAN and Freqtrade.

## File Structure

*   `backtrader_app.py`: The main Python script containing all the Backtrader logic. This includes data feed handling, strategy definition (SMA Crossover with stop-loss), Cerebro engine setup, analyzer integration, and detailed conceptual comments for further learning and framework comparisons.
*   `sample_imf_data.csv`: A sample CSV data file containing OHLCV (Open, High, Low, Close, Volume) data, used to demonstrate the bot's functionality out-of-the-box.
*   `README.md`: This file, providing an overview and instructions for the project.
*   `TUTORIAL.md`: (Anticipated) A step-by-step guide for setting up, understanding, and using the bot, including customization tips.

## Prerequisites

*   Python 3.7+
*   pip (Python package installer)

## Installation

1.  Clone the repository (or download the files).
2.  Navigate to the project directory:
    ```bash
    cd path/to/your/project-directory
    ```
3.  (Recommended) Create and activate a virtual environment:
    *   On Linux/macOS:
        ```bash
        python3 -m venv venv
        source venv/bin/activate
        ```
    *   On Windows:
        ```bash
        python -m venv venv
        venv\Scripts\activate
        ```
4.  Install required libraries:
    ```bash
    pip install backtrader matplotlib
    ```

## Running the Bot

Execute the main script from the project directory:

```bash
python backtrader_app.py
```

## Output

*   **Console Output:** The script will print detailed logs to the console, including:
    *   Buy/sell signals generated by the strategy.
    *   Order statuses (submitted, accepted, executed, canceled, etc.).
    *   Results of executed trades (price, cost, commission, profit/loss).
    *   Starting and final portfolio values.
    *   Key metrics from the integrated analyzers (Sharpe Ratio, SQN score, and a summary from TradeAnalyzer showing total trades, winning/losing trades, net PnL, etc.).
*   **Plot:** If the plotting functionality is enabled in `backtrader_app.py` (i.e., `cerebro.plot()` is not commented out), a plot window will typically appear after the backtest completion. This plot will display:
    *   A candlestick chart of the price data.
    *   Volume bars.
    *   The fast and slow Simple Moving Averages.
    *   Markers indicating buy and sell operations.
    If the script is run in a headless environment or if plotting has been intentionally disabled in the code, this graphical output will be skipped, and a message indicating this will be printed to the console.

    *   **Different Indicators:** Ideas for incorporating other technical indicators like RSI, MACD, Bollinger Bands, etc., into the strategy.
    *   **Alternative Sizers:** Using different position sizing strategies beyond the `FixedSize` sizer.

    *   **Adapting for Live Trading:** High-level considerations for transitioning the bot to a live trading environment (this requires significant additional setup, broker integration, and risk management adjustments).
*   Refer to the (anticipated) `TUTORIAL.md` file for a more detailed, step-by-step guide on using, understanding, and customizing the bot's components.

*   Review the conceptual comparisons to **QuantConnect LEAN** and **Freqtrade** in `backtrader_app.py` to understand different approaches to algorithmic trading system development.
